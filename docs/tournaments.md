# Tournaments

FLOW tournaments allow clans or ad-hoc teams to compete for credits, cosmetics, badges, and status.

Tournaments should be a major part of the platform over time.

## Goals

Tournaments should:

- Give players something bigger to compete in.
- Support both clans and ad-hoc teams.
- Create credit sinks through entry fees.
- Create credit rewards through prize pools.
- Reward serious competition.
- Give out rare cosmetics and badges.
- Create seasonal goals for the community.

## Tournament types

| Type                | Description                  |
| ------------------- | ---------------------------- |
| Open tournament     | Anyone can enter             |
| Clan tournament     | Only clans can enter         |
| Invite tournament   | Admin/invite-only            |
| Seasonal tournament | Runs as part of a season     |
| Regional tournament | Limited to a region          |
| Weekend cup         | Short event-style tournament |

## Entry fees

Tournament entry fees can be paid with credits.

| Tournament type     |      Entry fee |
| ------------------- | -------------: |
| Small open cup      |   250 per team |
| Clan battle cup     |   500 per clan |
| Weekend tournament  | 1,000 per team |
| Seasonal tournament | 2,500 per team |

Entry fees help prevent spam and create a prize pool.

Some tournaments may be free, especially for testing or community events.

## Prizes

Tournament prizes can include:

- Credits split across the team
- Expensive cosmetics
- Exclusive badges
- Seasonal trophies
- Clan profile cosmetics
- Server host rewards
- Nameplate styles

Example prize pool:

| Placement     | Prize                                                |
| ------------- | ---------------------------------------------------- |
| 1st place     | 5,000 credits split across team + exclusive cosmetic |
| 2nd place     | 2,500 credits split across team                      |
| 3rd place     | 1,000 credits split across team                      |
| Participation | Small badge or 100 credits                           |

## Team types

Tournaments can support different team types.

| Team type   | Description                                     |
| ----------- | ----------------------------------------------- |
| Clan team   | A team entered by a clan                        |
| Ad-hoc team | A temporary team created for the tournament     |
| Solo signup | Players sign up alone and are placed into teams |
| Invite team | Admin-approved or invited team                  |

Clan tournaments should probably use clan teams only.

Open tournaments can allow ad-hoc teams.

## Prize splitting

Credit prizes can be split across the players who participated.

Example:

A team wins 5,000 credits in a 5v5 tournament.

Each player receives 1,000 credits.

For clan tournaments, some or all of the prize could also go to the clan bank.

Possible split:

| Prize type            | Split                         |
| --------------------- | ----------------------------- |
| Open team prize       | Split across players          |
| Clan tournament prize | 70% players / 30% clan bank   |
| Clan-only cosmetic    | Sent to clan                  |
| Individual cosmetic   | Sent to participating players |

## Tournament cosmetics

Tournaments are a good place to award rare cosmetics.

Possible rewards:

- Winner badge
- Finalist badge
- Seasonal trophy
- Tournament MVP effect
- Tournament nameplate
- Clan banner
- Exclusive weapon skin
- Exclusive knife skin

These cosmetics should not always be available in the normal shop.

## Tournament rules

Tournament rules should define:

- Format
- Map pool
- Match length
- Team size
- Server selection
- Region rules
- Substitutes
- No-show handling
- Pause rules
- Dispute handling
- Prize splitting

## No-shows and penalties

No-shows waste time and server resources.

Suggested penalties:

| Action                   |                Penalty |
| ------------------------ | ---------------------: |
| Team no-show             | -300 from team or clan |
| Repeated no-show         | Tournament restriction |
| Abandon tournament match | -500 from team or clan |
| Fake tournament entry    |         Tournament ban |

## Server selection

Tournament matches should run on verified FLOW servers.

Server selection should consider:

- Region
- Player latency
- Server rating
- Server performance
- Tournament importance
- Server availability

High-stakes tournament matches should prefer higher-rated servers.

## Notes

Tournaments should probably come after the basic platform, credits, cosmetics, clans, and server verification are working.

They are important, but they rely on the rest of the platform being stable first.
